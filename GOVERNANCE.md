# Governance

WHOAYO is currently founder-led. The owner sets product direction, appoints maintainers, approves releases and makes legal/commercial decisions. Maintainers may review issues and code only within delegated permissions.

Security, privacy, evidence semantics, spending, licensing, provider enablement and public release are protected decisions. Automated tests and AI reviews inform them but do not authorize them.

Material technical changes use pull requests with documented user impact, threat-boundary effect and validation. Releases require a human approval tied to an exact commit. Historical evidence is never rewritten to make a release appear cleaner.

The initial repository owner is [M2201](https://github.com/M2201). On October 14, 2026, the owner approved public release at `M2201/whoayo` under AGPL-3.0-only with issues-only contributions. This is founder-led governance. Outside code acceptance and any separate commercial license require published terms before they are offered.
