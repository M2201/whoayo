# Support

## Community support

Use [GitHub issues](https://github.com/M2201/whoayo/issues) for reproducible product bugs and focused feature requests containing synthetic data only. The repository does not provide legal, patent, security certification or emergency incident advice.

Before filing:

```sh
node --version
npm ci
npm run check:source
npm test
npm run build
```

Include the commit, operating system, Node version, expected/actual behavior and the smallest synthetic reproduction. Redact private paths and identifiers.

## Security and private material

Follow `SECURITY.md`. Do not post credentials, private concepts, timestamp packages, customer records or screenshots containing them.

## Managed service

No public managed service or paid support plan is live. Response times, pricing and eligibility in planning documents are proposals, not purchased commitments.
