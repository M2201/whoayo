# Roadmap

The order is risk-driven. Dates are intentionally omitted until owners, vendors and acceptance evidence exist.

## Now: public local foundation

- [x] private idea records, immutable versions and exports;
- [x] exact-request approval and provider-neutral text adapters;
- [x] timestamp-before-AI gate with honest proof-status boundaries;
- [x] monetary reservation/estimate ledger and modeled unit economics;
- [x] source allowlist, secret checks, CI package and community documentation;
- [ ] owner-approved license, exact GitHub destination and public push;
- [ ] tagged first public release and checksum-backed release notes.

## Next: limited managed pilot

- [ ] production hosting/TLS/DNS with private data services;
- [ ] provisioned managed identity, MFA, recovery and invitations;
- [ ] external KMS/key rotation and tenant-isolation review;
- [ ] Stripe catalog, Checkout, portal, signed idempotent webhooks and entitlements;
- [ ] scheduled encrypted backups plus independently observed restore drills;
- [ ] approved timestamp authority/calendar operation and monitoring;
- [ ] provider live acceptance under dedicated accounts and small budgets;
- [ ] privacy notice, terms, support contact and incident process;
- [ ] ten design-partner acceptance and retention evidence.

## Then: full build workspace

- [ ] isolated sandbox with bounded compute and outbound-network policy;
- [ ] GitHub/GitLab authorization, worktrees, patches and human-approved PR flow;
- [ ] organization membership, roles and shared projects;
- [ ] cost-aware model routing with evaluations, never silent substitution;
- [ ] source-backed research connectors and citation receipts;
- [ ] customer-controlled deletion/retention and export portability.

## Explicitly out of scope until separately governed

Autonomous production deployment, patent/originality verdicts, surveillance-style aggregation, sanctions, automatic licensing decisions and unapproved publication of private records.
